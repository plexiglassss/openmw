Proximity Tool - Sparse HUD

This optional overlay is for the repaired Proximity Tool menu used in the November 10 capture. It updates the changed distance labels and direction arrows together. Reordering markers, fading, resizing, visibility changes and newly added rows use the normal window refresh. It uses the existing retainedParts.lua supplied with the repaired menu.

Extract this folder to your mods directory and add it after the repaired Proximity Tool and its other script fixes under Data Directories. You can also add this directory straight from the extracted engine under tools/combined-performance. Restart OpenMW. Remove this one data directory to restore the previous script. No ESP or saves need changing.

The engine and its previous four native-job adapters work independently of this optional overlay. On older engines the script uses the existing window update method.
