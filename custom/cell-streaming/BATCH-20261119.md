# Cell transition batch — 19 November 2026

This build extends ba93fd8e and preserves its cumulative engine and UI features.
Replace the complete engine distribution, including resources. Keep the current
Inventory Extender Redone, UIToolkit, QuickLoot and other companion mods.

Changes:

- Renderer unload selects only the departing cell's animations. Membership follows
  movement, removal and re-insertion; actor listener teardown remains synchronous.
- Door and grid plans reuse topology. Current door state, positions, destinations,
  distance ordering and cache-hit timestamp refreshes are still evaluated. Pending
  normalized mesh-template requests coalesce only within matching model/VFS revisions.
- Preload eviction retains recently useful, costly completed preparation for at
  most two extra seconds relative to recency. The existing one-second admission
  grace, cache-entry capacity and expiry still apply. Queue delay is not treated
  as resource preparation cost.
- Detached cleanup yields after at most 64 references or approximately 2 ms;
  resource cleanup yields between managers. One destructor or one manager is
  indivisible. Arriving work normally runs first; maintenance receives a slice
  after at most eight ordinary dispatches. Queued detached references are capped
  at 16,384; extreme backlog applies measured backpressure rather than retaining
  an unlimited queue. This is a reference-count cap, not a byte measurement.

Comparison switches (unset/default = enabled; set to 0 before starting OpenMW):

| Change | Environment variable |
| --- | --- |
| Renderer cell membership | OPENMW_CELL_OBJECT_INDEX |
| Preload plans and pending mesh coalescing | OPENMW_PRELOAD_PLAN_CACHE |
| Cost-sensitive preload retention | OPENMW_PRELOAD_RETENTION |
| Cooperative cleanup | OPENMW_SLICED_CLEANUP |

Set all four to 0 for the earlier scheduling policies; ownership transfer and
shutdown correctness fixes remain enabled. OPENMW_COMBINED_PERFORMANCE=0
also disables them, but additionally disables older improvements, so it is a
broader comparison. Restart between comparisons; switches are process-local.

The existing timing recorder (`OPENMW_TIMING_FILE`) includes renderer unload,
preload planning, cache eviction, cleanup slices and backlog waits. Resource
statistics include visited/removed animations, plan builds/reuses, coalesced mesh
requests, cost-sensitive eviction choices, peak queued references and cap waits.
